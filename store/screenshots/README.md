# Play Store screenshots

Captured on the `pikadex_test` emulator (1080x2400, density 420), light mode, from a fresh
install — the same defaults a real first-time user sees, since a promotional screenshot in an
unusual configuration (staged dark mode, unusual data) can look inconsistent with the actual app.
The Team screenshot has 4 Pokémon staged temporarily to show a non-empty state (shared weaknesses,
suggestions); the roster was cleared back to empty afterward so this didn't leave test data behind
on the emulator's persisted app state.
