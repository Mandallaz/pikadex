# PikaDex

An Android Pokédex app powered by [PokeAPI](https://pokeapi.co/).

## Features

- **Pokédex** — search, filter (type, move, ability, tier, stats...), sort
- **Pokémon detail** — stats, type matchups (with a Terastallization preview), evolutions, moves, cries, Smogon links
- **Team builder** — weaknesses/coverage analysis, suggestions, 81 preset teams
- **Type Triangles** — reference for the 16 type match-up cycles
- Offline mode, favorites, dark mode

## Development

```bash
./gradlew testDebugUnitTest   # unit tests
./gradlew assembleDebug       # debug build
```
