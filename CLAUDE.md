# PikaDex — project-specific instructions

## Backlog tracking

[GitHub Issues](https://github.com/Mandallaz/pikadex/issues) is the single source of truth for the backlog. `BACKLOG.md` was retired (2026-08-09) — kept locally, untracked, as a historical archive only; do not update it.

- New feature discussed → create a GitHub issue (title `F<n> — <name>`, full spec in the body, labelled `priority: <level>` and `status: to-groom`/`plan-ready`).
- Status change (grooming → plan ready → done, or cancelled) → update the issue's labels/state (`state_reason: completed` when done, `not_planned` when cancelled).
- When an issue is labelled `status: done`, close it on GitHub.
