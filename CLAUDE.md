# PikaDex — project-specific instructions

## Backlog tracking

[GitHub Issues](https://github.com/Mandallaz/pikadex/issues) is the single source of truth for the backlog. `BACKLOG.md` was retired (2026-08-09) — kept locally, untracked, as a historical archive only; do not update it.

- New feature or bug discussed → use the `feature-issue` skill to create the GitHub issue (title/numbering, labels, complexity estimate, testing requirement — see the skill).
- Status change (grooming → plan ready → done, or cancelled) → use the `close-issue` skill.
